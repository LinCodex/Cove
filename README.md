# Cove - SMS Autoresponder Landing Page

A fast, modern web landing page for **Cove**, the Android SMS Autoresponder tool.

## Features

- **Pixel-Perfect UI**: Dark theme landing page with smooth styling and responsive typography.
- **Direct APK Download**: Bundles and serves the Android debug APK package.
- **Pure CSS Layout**: Zero-bloat, responsive design.

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 18
- Vite
- Lucide Icons
- Canvas Confetti
